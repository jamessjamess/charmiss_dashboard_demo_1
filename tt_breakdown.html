Return Rate (CN)
อัตราการคืนสินค้า = Total CN (มูลค่าใบลดหนี้ที่ฝ่ายบัญชีออกให้) ÷ Total Invoice (ยอดขายก่อนหักคืน) ของเดือนเดียวกัน (ไม่ offset ข้ามเดือน) เป็นสัญญาณล่าช้า (Lagging Indicator) ของปัญหาสต็อกหรือคุณภาพสินค้าหน้าร้าน — "ล่าช้า" ในที่นี้หมายถึงสะท้อนปัญหาที่เกิดขึ้นก่อนหน้าแล้ว ไม่ใช่การหน่วงเดือนในการคำนวณ เส้นประสีแดงคือเพดานเป้าหมายที่ไม่ควรเกิน 2% (เกณฑ์เดียวกับที่การ์ด High Return Rate Stores ทางขวาใช้)

High Return Rate Stores
รายชื่อร้านค้าที่มีอัตราคืนสินค้า (CN Rate) ในช่วงเวลาที่เลือก เกิน 2% (เป้าหมายเดียวกับเส้นประในกราฟ Return Rate (CN) ทางซ้าย) เรียงจากอัตราคืนสูงสุดไปต่ำสุด — เนื่องจากค่าเฉลี่ยทั้งพอร์ตตอนนี้สูงกว่า 2% อยู่แล้ว จึงอาจเห็นร้านเกือบทั้งหมดติดในลิสต์นี้ นั่นคือสัญญาณว่าปัญหาคืนสินค้าเป็นภาพรวมทั้งพอร์ต ไม่ใช่แค่บางร้าน ลำดับ (สูงสุดก่อน) ยังใช้เป็น call list ได้ตามปกติ แสดงสูงสุด 6 ร้านแรกในกราฟ ถ้ามีมากกว่านั้นกด "See all" เพื่อดูรายชื่อทั้งหมดแบบตาราง

New vs Inactive Stores
แท่งขึ้น (บวก) = New ร้านที่สั่งซื้อครั้งแรกในเดือนนั้น แท่งลง (ลบ) = Inactive ร้านที่เคย Active ในเดือนก่อน แต่เดือนนี้ไม่มีคำสั่งซื้อเลย เส้นประ = Net Change (New − Inactive) อธิบาย movement ของ Active Stores ในเดือนนั้นโดยตรง คำนวณ Inactive จาก: ฐาน Active เดือนก่อน + ร้านใหม่เดือนนี้ − Active เดือนนี้ Retention Rate = 100% − Inactive Rate · หมายเหตุ: ธุรกิจ Traditional Trade การไม่สั่งซื้อ 1 เดือนอาจแค่แปลว่าสต็อกยังไม่หมด ไม่ใช่ Churn จริงเสมอไป — Churn ที่ผ่านเกณฑ์ยืนยัน (เช่น ไม่สั่งเกิน 45 วันต่อเนื่อง) เป็นขอบเขตของ Module 2
New = first order this month · Inactive = no order this month
